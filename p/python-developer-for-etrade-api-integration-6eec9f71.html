1. OAuth 1.0a handshake. Wire the full flow - request token, authorize for the verifier, exchange for the access token - in the ETRADE sandbox first, then flip to production.

2. Account and market data. Pull account list, balances, portfolio, and quotes, normalized into clean Python models.

3. Preview then place. Call previewOrder for the previewIds, surface them, then placeOrder, so nothing fires without a confirmed preview.

4. Token renewal. ETRADE tokens go inactive after two hours idle and expire at midnight ET, so I add a scheduler that renews automatically.

5. Errors, logging, persistence. Structured logging, retry with backoff on transient failures, and PostgreSQL for tokens, order history, and an audit trail.

6. Deployment. Containerized with secrets management, sandbox-verified before production.
