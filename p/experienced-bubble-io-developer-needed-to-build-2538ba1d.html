1. Data model first - a scalable schema for User, Agent Office, Specialization, and Content, with privacy rules enforcing agent vs admin access.

2. Auth and roles - registration, login, and role-based permissions wired into privacy rules so agents only touch their own office.

3. Agent office and auto-generated site - a dashboard per agent plus a public profile on their subdomain. True agent.yourdomain.com needs a Cloudflare Worker in front of Bubble; path-based is faster.

4. Onboarding and supervision - guided onboarding, a specialization picker, and a supervision view for oversight.

5. Social and content - connect accounts via Bubble's API Connector with OAuth, then content creation and management.

6. Admin dashboard - manage users, content, and operations in one place.
