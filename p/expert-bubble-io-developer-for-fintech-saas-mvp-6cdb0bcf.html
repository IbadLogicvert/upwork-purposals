Milestone 1: I model your 4 core Data Types from the SoW, then build the 4-step onboarding questionnaire and the gamified Unclaimed Cash dashboard.

Milestone 2: Plaid plugin to authenticate a sandbox bank and pull read-only transactions. OpenAI wired through the API Connector with a strict JSON schema to categorize the messy transaction strings. Documint mapped to your legal templates, saving each returned PDF URL back to Bubble.

Milestone 3: Backend workflows that run the tax logic, calculate Plaid totals, and update the UI the moment a user secures a deduction. Plus the year-to-date export that aggregates categories onto Schedule C and Form 4562 fields.

Milestone 4: Standby QA with your 3 alpha users, refining payloads and squashing logic and UI bugs against real bank data.
